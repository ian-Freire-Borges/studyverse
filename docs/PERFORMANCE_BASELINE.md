# Linha de base

Não existia Bomb Arena neste repositório antes desta alteração; portanto não há comparação de FPS, rede, CPU ou memória anterior ao jogo. Não é correto apresentar o quiz ou o estilingue como baseline do Bomb Arena.

Ambiente das medições locais: Windows 10.0.26200, AMD Ryzen 5 5600GT, 12 processadores lógicos, cerca de 7 GiB de RAM visível, Node 24.18.0 e Chrome sem interface gráfica. Celular foi apenas emulado. Metas de 60 FPS desktop e mobile são objetivos, não garantia.
